# 4astore - Local Grocery & Daily Needs Store

A fully functional static e-commerce website for a local grocery/general store serving Chandargarh, Nabinagar, Aurangabad, Bihar – 824301.

## Features

- Modern, responsive design (mobile-first)
- Product browsing with categories and filters
- Search functionality
- Shopping cart with LocalStorage persistence
- PIN code delivery validation (824301 only)
- Checkout with order placement
- Order history
- WhatsApp order notification
- Toast notifications
- Bottom mobile navigation

## Setup

1. Clone or download the project
2. Serve with any local server:
   - VS Code Live Server extension
   - `npx serve .`
   - `python -m http.server 8000`
3. Open in browser

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Bootstrap 5
- LocalStorage for data persistence
- JSON files for product/category data
